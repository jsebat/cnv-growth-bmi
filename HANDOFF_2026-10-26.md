## What was done since 2026-10-24
1. **Polygenic scores for the sex/PGS sensitivity analysis.** SSC had no childhood obesity, childhood BMI, height or autism-2026 scores,
   so the SSC genotype set was scored on Expanse with Anjali's SBayesRC weights (`jsebat/pgs_obesity_ssc/`: jobs 55296649 obesity/BMI,
   55296998 height + G2MH autism). Autism for SSC uses the existing leave-SSC-out score (`jsebat/pgs_asd2026_loo/scores/ssc.asd2026_loSSC.sscore`);
   G2MH WGS carriers were scored with the full April-2026 weights (G2MH is not a GWAS cohort). Raw and processed scores:
   `Jon/Claude/CNV_growth_trajectories_data/{ssc_scores_raw, g2mh_scores_raw, ssc_pgs_scores.tsv}`. Residualised on 10 PCs and z-scored within cohort.
2. **Tables S4-S6** (`30a_build_ssc_pgs.R`, `30_sex_pgs_sensitivity.R`): S4 strata (sex; below/above-median childhood obesity, adult BMI,
   height, autism PGS; carriers and controls stratified alike); S5 confounding check (BMI slope and CNV x BMI vs controls unadjusted,
   + sex, + each PGS, + all four, + all four + sex, same individuals); S6 power for modifier x BMI interactions. Conclusion: BMI effects
   are not explained by sex or PGS; of 47 well-powered interaction tests 7 are nominal, none survives correction; only the adult-BMI-PGS
   x BMI effect on height/HC is directionally consistent and worth a larger sample.
3. **Analysis_report_2026-10-26.docx**: full methods, results, legends, table index, sample sizes, paths (Dropbox + Expanse), PMID references.
4. Lab GWAS sheet copied to `resources/GWAS_summary_statistics_sheet_2026-10-26.csv`; SBayesRC pipeline copies recorded (section below).
5. **ASD diagnosis within CNV group (added later on 2026-10-26; `32_supp_asd_by_cnv.R`)**: restores the "head circumference by autism diagnosis
   within CNV" panels as supplementary figure `fig_supp_asd_by_cnv` (A height, B head circumference, C BMI; carriers with vs without ASD per
   locus, pooled overgrowth/undergrowth, SSC probands vs siblings; GAM y ~ ASD + s(age) + sex [+ cohort + locus]). Statistics in Table S7
   (`supp_table_S7_asd_by_cnv.csv`, sheet "S7 ASD by CNV") and the sex/PGS sensitivity in Table S8 (`supp_table_S8_asd_by_cnv_pgs_adjusted.csv`,
   sheet "S8 ASD by CNV PGS adj"; same individuals, + each PGS, + all four). Both tables also carry the ASD x carrier interaction (ASD effect in the
   carrier group minus the ASD effect in SSC non-carriers; HC overgrowth +0.35, p = 0.046; BMI all null). Result: HC larger with ASD in overgrowth CNVs (+0.45 SD, p = 0.022),
   not in undergrowth; BMI does not differ by ASD within any CNV group; PGS adjustment changes nothing. Report sections 2.8, 3.7 and
   `figure_legends.md` updated; the report is rebuilt with `Rscript 31_make_report.R <out.docx>` (the path argument is required).
6. **Medication sensitivity extended to height and head circumference (2026-10-26; `27_medication_sensitivity.R`)**: 27 now sources 23
   (`UNAFF_DRAW_FIG=FALSE`) and adds the G2MH carriers' main-figure growth rows (GUID via genomatrix id) to the SRS/SCQ/CNB table.
   Within-carrier BMI slopes on height and HC are unchanged by medication adjustment or by excluding medicated carriers (HC 16p11.2 del
